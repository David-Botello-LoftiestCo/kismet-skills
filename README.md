# Kismet Skills Marketplace

Marketplace oficial de skills para agentes de inteligencia artificial para el equipo de Kismet.

## Instalación para el equipo

```
/plugin marketplace add https://github.com/David-Botello-LoftiestCo/kismet-skills
```

## Plugins disponibles

| Plugin | Descripción |
|---|---|
| **kismet-brand** | Identidad visual corporativa de la marca Kismet aplicada a cualquier entregable. |
| **kismet-project-bootstrap** | Inicializa proyectos nuevos de Kismet con contexto operativo, marco normativo (telesalud, datos de salud, pagos) y knowledge base corporativo en Notion. |

## Actualización

```
/plugin marketplace update kismet-skills
```

Cada commit al repo queda disponible al equipo tras correr este comando.

## Cómo contribuir

1. Clona el repo
2. Crea una rama `feature/<nombre>`
3. Modifica o agrega plugins bajo `plugins/`
4. PR a `main`
5. Al merge, anuncia al equipo que corran `/plugin marketplace update`

## Créditos

Estas skills son propiedad de **Kismet**: identidad de marca, contenido y criterios normativos le pertenecen. **Loftiest Corporation** actúa únicamente como proveedor de código para el desarrollo de la plataforma.
